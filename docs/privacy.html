Privacy Policy

Last updated: November 27, 2026 · Developer: Badger Dev

This Privacy Policy explains how Badge Deleter for Roblox handles data when you use the browser extension.

1. Account Credentials & Roblox Data

  • The extension does not collect, read, store, or transmit your Roblox username, password, user ID, badge names, or .ROBLOSECURITY session cookie.
  • All badge-listing and badge-deletion requests are sent directly from your browser to official *.roblox.com endpoints using your existing logged-in browser session.

2. Operational Diagnostics (Chrome Build)

To detect broken Roblox endpoints and extension errors, the Chrome build sends anonymous, non-personal operational events (such as inventory load failures, batch completion counts, error category codes, extension version, and browser UI locale) to Google Analytics 4 using a randomly generated per-install UUID stored locally in browser CacheStorage. Numeric Roblox user IDs and badge IDs are scrubbed before any diagnostic string is sent.

3. Zero Data Collection (Firefox Build)

The Firefox Add-ons (AMO) build automatically disables all analytics and telemetry requests and collects zero data.

4. Third-Party Sharing & Sales

We do not sell, rent, or trade user data to third parties, and we do not display advertisements or track browsing history across websites.

5. Contact & Source Code

The full source code is publicly auditable at github.com/Vector-Badger/roblox-badge-deleter. Questions or privacy requests may be submitted via the repository's GitHub Issues page.
