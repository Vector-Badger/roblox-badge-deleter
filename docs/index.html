Badge Deleter for Roblox

An open-source Chrome and Firefox extension that helps users filter, whitelist, and mass-delete unwanted Roblox inventory badges safely in the background.

  • Zero invasive permissions: Uses "permissions": [] and never reads or stores .ROBLOSECURITY cookies.
  • Adaptive background execution: Automatically paces requests and recovers from Roblox rate-limit cooldowns even when the popup is closed.
  • Transparent source code: Every release is built directly from the public repository with automated unit tests.
